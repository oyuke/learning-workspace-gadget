# Learning Workspace ガジェット（配布用）

Learning Workspace を Windows のデスクトップに常駐させて操作するアプリのインストーラー置き場です（ソースコードは含みません）。

## インストール

1. [Releases](../../releases/latest) から `Learning Workspace Setup x.y.z.exe` をダウンロードして実行します。
2. 初回は Windows の SmartScreen が警告を出すことがあります。「詳細情報」→「実行」で進めてください（コード署名をしていないためです）。
3. 起動するとログイン画面が出るので、Learning Workspace のアカウントでログインします。

アクセス権（Cloudflare Access の許可）がないアカウントでは、ログインしても中身は使えません。

## 使い方

- 画面右下の円にマウスを乗せると機能が展開し、クリックでカードが開きます。
- ショートカットキー（既定 Ctrl+Alt+Space）で表示・非表示。変更は「設定 → 環境設定」から。
- 新しい版は自動で見つかり、環境設定から再起動して更新できます。
